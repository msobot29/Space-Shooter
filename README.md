# Space Shooter (Godot 4)

A small playable vertical arcade shooter inspired by classic space games.

## Run
1. Install Godot 4.x (standard edition).
2. Open Godot Project Manager, choose **Import**, and select `project.godot`.
3. Press **F6** with the scene open, or **F5** to run the project.

## Controls
- A / D or left / right arrows: move
- Space or left mouse button: fire
- Enter: restart after game over

## Features
- Player spaceship and projectiles
- Enemy formations and wave progression
- Collision detection, score and lives
- Procedural placeholder graphics (no external assets)

This is an initial prototype, not yet tested in a local Godot runtime.
